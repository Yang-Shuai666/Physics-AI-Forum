团队协作流程

  1. 每周在 reports/ 新建周报 Markdown（可直接网页提交）。
  2. 创建“周报讨论” Issue，填写周报链接与讨论问题。
  3. 围绕周报在 Issues 继续讨论并跟进行动项。
  4. 可选：通过 PR 审核并使用 GitHub Pages 展示周报列表。
